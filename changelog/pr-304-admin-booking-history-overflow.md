# Buchungen und Änderungsverlauf bleiben im Rahmen

- Lange Buchungsbeschreibungen brechen in der Admin-Ansicht innerhalb der verfügbaren Tabellenspalte um.
- Buchungs- und Änderungsprotokoll bleiben auf Laptop- und Desktop-Breiten vollständig in ihren Panels.
- Die bestehende mobile Kartenansicht bleibt unverändert erhalten.
