# Push-Empfänger ohne E-Mail-Adresse und Editor-Zugriff beim Informationsversand

- Behebt ein Problem, bei dem Teilnehmer ohne gültige E-Mail-Adresse bei Push-Nachrichten nicht ausgewählt werden konnten.
- Zeigt im Formular `InformationEmailForm` alle aktiven Lager-Teilnehmer an (Teilnehmer ohne E-Mail-Adresse erhalten den Hinweis `(Keine E-Mail)`).
- Gestattet Redakteuren (`@editor_required`) den Zugriff auf die Seite zum Erstellen und Versenden von Informationen (E-Mail, Push, Kiosk-Ankündigung).
